# SAC EASE

Плагин SketchUp для подготовки архитектурной модели к импорту в EASE 4 или EASE 5. Он находит щели, отверстия внутри граней, вывернутые плоскости, листы без толщины, лишнюю детализацию и грани без тегов, затем исправляет то, что можно исправить без удаления декора.

Нужен SketchUp 2019 или новее. Запись DWG/DXF есть в SketchUp Pro.

## Установка

Один и тот же файл ставится на Mac и на Windows. Нужен SketchUp 2019 или новее.

1. Скачайте `dist/SAC_EASE.rbz` из репозитория.
2. В SketchUp откройте **Window → Extension Manager → Install Extension…** и выберите этот файл.
3. Если SketchUp спросит про неподписанное расширение, разрешите загрузку.
4. Перезапустите SketchUp.

Кнопка **SAC** открывает проверку. Та же команда: **Extensions → SAC EASE → Подготовка для EASE**.

Если панели не видно:

- Windows: **View → Toolbars → SAC EASE**
- Mac: **View → Tool Palettes → SAC EASE**

Можно поставить без менеджера расширений, двойным щелчком по файлу из папки проекта:

- Mac: `install_mac.command`
- Windows: `install_windows.bat`

## Что делает проверка

- Замкнутость оболочки и оценка объёма зала
- Щели между группами и почти совпавшие вершины
- Отверстия внутри грани, невыпуклые грани, слишком дробные дуги
- Лицевая сторона зала — внутрь помещения; у внутренних тел — в воздух зала
- Перегородки и экраны без толщины
- Мелкие грани, короткие рёбра, объекты, похожие на кресла и декор
- Теги как будущие акустические материалы, текстуры и цвет Default

Кнопка «Исправить безопасное» сваривает близкие вершины границы, закрывает плоский проём гранью, сливает компланарные грани с одним тегом, разворачивает лицевые стороны и разрезает отверстия на треугольники. Кресла, плинтусы и скрытую геометрию она не удаляет: для этого есть отдельные кнопки у замечаний.

Ориентация считается по замкнутой оболочке. Самый большой замкнутый объём — зал, его лицевые стороны должны смотреть внутрь. У остальных тел лицевые стороны смотрят наружу, в воздух зала. Зеркальные копии компонента плагин не переворачивает: сначала Make Unique.

## Экспорт

EASE 4 — DXF, EASE 5 — DWG. В файл попадают плоские 3D-грани AutoCAD 2013, без рёбер, размеров, текста, направляющих и материалов. Имена тегов сохраняет сам экспортёр SketchUp как слои.
