# SAC EASE

Плагин SketchUp для подготовки архитектурной модели к импорту в EASE 4 или EASE 5. Он сверяет модель с правилами импорта EASE 4 из SketchUp: лицевая сторона оболочки снаружи, двусторонние грани на слое с `$`, отверстия колонн и ниш, проём в соседний объём, щели, детализация и теги. Исправляет то, что можно исправить без удаления декора.

Нужен SketchUp 2019 или новее. Запись DWG/DXF есть в SketchUp Pro.

## Установка

Один и тот же файл ставится на Mac и на Windows. Нужен SketchUp 2019 или новее.

1. Скачайте `dist/SAC_EASE.rbz` из репозитория.
2. В SketchUp откройте **Window → Extension Manager → Install Extension…** и выберите этот файл.
3. Если SketchUp спросит про неподписанное расширение, разрешите загрузку.
4. Перезапустите SketchUp.

Кнопка **SAC** открывает проверку. Та же команда: **Extensions → SAC EASE → Подготовка для EASE**.

Если панели не видно:

- Windows: **View → Toolbars → SAC EASE**
- Mac: **View → Tool Palettes → SAC EASE**

Можно поставить без менеджера расширений, двойным щелчком по файлу из папки проекта:

- Mac: `install_mac.command`
- Windows: `install_windows.bat`

## Что делает проверка

- Замкнутость оболочки и оценка объёма зала
- Щели между группами и почти совпавшие вершины
- Отверстия внутри грани, невыпуклые грани, слишком дробные дуги
- Лицевая сторона зала — наружу, чтобы снаружи была видна серая сторона; у внутренних тел — в воздух зала
- Двусторонние грани и окна на слое `Лицевой $ Тыльный`; дверь без символа `$`
- Отверстие колонны или ниши можно оставить: импорт EASE 4 сделает покрытие Coat of. Если за отверстием есть другой объём, грань нужно разрезать
- Слишком тонкие замкнутые тела
- Мелкие грани, короткие рёбра, объекты, похожие на кресла и декор
- Теги как будущие акустические материалы, текстуры и цвет Default

Кнопка «Исправить безопасное» сваривает щели на краю оболочки и закрывает гранью только настоящий разрыв. Отверстие колонны, ниши или окна внутри грани она не заливает: для EASE это покрытие Coat of, и зал с такими отверстиями считается замкнутым. Компланарные грани сливаются, только когда SketchUp сам подтверждает общую плоскость: иначе стирание ребра удаляет обе грани. Лицевые стороны разворачиваются, когда объём зала отрицательный. Кресла, плинтусы и скрытую геометрию она не удаляет: для этого есть отдельные кнопки у замечаний.

Ориентация считается по замкнутой оболочке. Самый большой замкнутый объём — зал, его лицевые стороны смотрят наружу: так Check Data получает положительный объём. У остальных тел лицевые стороны тоже смотрят наружу, в воздух зала. Зеркальные копии компонента плагин не переворачивает: сначала Make Unique.

Слой с одним знаком `$` и именем по обе стороны — признак Two-Fold при импорте SketchUp в EASE 4. Окно: `Окна $ Окна`. Перегородка, открытая с двух сторон: `Экран $ Экран` или `Лицевой $ Тыльный`. Дверь остаётся на обычном слое.

## Экспорт

EASE 4 — DXF, EASE 5 — DWG. В файл попадают плоские 3D-грани AutoCAD 2013, без рёбер, размеров, текста, направляющих и материалов. Имена тегов сохраняет сам экспортёр SketchUp как слои.
